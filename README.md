# Portfolio Website 🌐

Welcome to my personal portfolio website! This project is a simple and clean two-page website built using **HTML** and **basic CSS**. It showcases an overview of who I am and provides an easy way to get in touch with me.

## ✨ Features

- **Home Page**:  
  - Introduces me and my work in a clear, concise layout.  
  - Highlights key information such as skills and a brief bio.  

- **Contact Page**:  
  - Provides a form for visitors to reach out directly.  
  - Displays contact details for easy communication.

## 🛠️ Technologies Used

- **HTML5**: For the structure and content of the website.  
- **CSS3**: For styling and layout.

## 🎯 Purpose

This project is a simple yet effective digital presence that highlights my skills and offers a direct way to connect. It demonstrates my foundational skills in web development and serves as a starting point for future enhancements.

## 🚀 How to View

1. Clone or download this repository.  
2. Open the `index.html` file in your browser to explore the Home Page.  
3. Navigate to the Contact Page by clicking the appropriate link.

Alternatively, you can check out the live demo - https://sanjailaksh19.github.io/portfolio-simple-website/
